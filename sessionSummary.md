### Problems Encountered & How They Were Resolved
- **`ECONNREFUSED ::1:8000` on first API call** → Windows resolves `localhost` to IPv6 `::1` but uvicorn binds to IPv4. Fixed by hardcoding `127.0.0.1` in both `next.config.mjs` (proxy destination) and the uvicorn startup command in `package.json`.
- **Next.js 16 install failed** → Node v18 is installed; Next.js 16 + `@tailwindcss/oxide` require Node ≥ 20. Downgraded to Next.js 14 + Tailwind CSS v3, and replaced all Tailwind v4 syntax in the generated scaffold files.
- **`next.config.ts` rejected at build** → Next.js 14 doesn't support `.ts` config files. Renamed to `next.config.mjs` and removed the TypeScript type annotation.
- **429 rate-limit crash (ASGI process died)** → The `ClientError: 429` from Gemini propagated up through the async generator chain uncaught, killing the server. Wrapped `runner.run_async()` in `try/except` in `session_manager.py`; on 429 it now yields a friendly `error` SSE event with the retry delay, then closes cleanly.
- **Agent status never visible** → The pipeline status pill was rendered inside the scrollable messages div — it appeared below all messages and scrolled out of view. Moved to a fixed slot between the message list and the input bar, and redesigned as a 4-step pipeline tracker with checkmarks for completed steps.
