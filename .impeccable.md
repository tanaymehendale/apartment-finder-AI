## Design Context

### Users
A single owner (Firebase Auth-gated to one email — not a public product) using the tool during
active apartment-hunting sessions: multi-turn chat to state requirements (city, budget, landmark,
optional beds/baths/roommates/proximity), then reviewing up to 5 AI-ranked listings with commute
times, safety notes, and a map, to decide where to live. A real financial/lifestyle decision, not
casual browsing — sessions happen at a desk, often with the map panel open alongside results.

### Brand Personality
Warm and approachable. Apartment hunting is inherently stressful (budget pressure, unfamiliar
neighborhoods, a big decision on a deadline); the interface should actively de-stress it rather than
read as a sterile data dashboard. Three words: **warm, reassuring, human.** Friendlier microcopy,
softer edges, a gentler palette — while still respecting that this is a research tool the user needs
to trust with money and safety information, not a toy.

### Aesthetic Direction
**Light mode only** (matches actual usage — daytime research sessions, pairs with the existing
Mapbox `satellite-streets-v12` basemap; no dark-mode/theme-toggle work in scope for P4-3).

**Anti-reference (what to move away from):** the current UI — Inter font, flat `#1A56DB` blue,
generic Tailwind `rounded-2xl` + `shadow` cards, raw emoji used as icons (🚗, ⭐, 🤫). This reads as
default "AI-generated" output and is exactly what P4-3 exists to fix.

**Direction:** a warm, human palette (neutrals tinted toward a soft accent hue, not stark white/blue),
a distinctive type pairing (reject Inter and the other reflex/monoculture fonts), a real SVG icon set
replacing every emoji, and motion/spacing that feels considered rather than templated (staggered card
reveals, skeleton loaders, calm easing — no bounce).

### Design Principles
1. **Warmth through color & type, not decoration.** Tint neutrals toward a soft, human accent hue
   (small chroma shift is enough); pair a distinctive display face with a refined, readable body face
   — no Inter, no other font from the skill's reflex-reject list.
2. **De-stress the decision.** Generous whitespace, calm/reassuring microcopy over sterile data
   dumps, motion used for orientation (staggered reveals) not spectacle.
3. **Respect the data density.** This is a research tool — 5 ranked cards each carrying price,
   beds/baths, commute, proximity badges, and safety notes. Warmth must not come at the cost of
   scanability; use clear hierarchy (type scale, spacing rhythm) rather than clutter or over-cropping
   information.
4. **No decorative crutches.** No emoji-as-icon, no generic card-grid-with-icon-heading-text
   templates, no side-stripe borders, no gradient text (per the skill's absolute bans) — build a
   small custom SVG icon set that matches the warm tone instead.
5. **Light-only, accessible.** WCAG AA contrast throughout, visible focus rings, ARIA on interactive
   elements (chat cards, map markers, action buttons) — P4-3's explicit scope — and must hold up
   against the satellite-streets Mapbox basemap already in use.
